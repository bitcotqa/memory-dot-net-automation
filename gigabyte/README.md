# Gigabyte Memory Automation Scripts

QA automation scripts for verifying Gigabyte memory compatibility data on memory.net.

| Script | Purpose |
|---|---|
| `amd.py` | Verifies memory data for Gigabyte AMD-based systems |
| `intel.py` | Verifies memory data for Gigabyte Intel-based systems |
| `oldintel.py` | Verifies memory data for older Gigabyte Intel-based systems |
| `gigabyte_processor_family_line.py` | Verifies processor family and product line |
| `gigabyte_serverdimm_rank.py` | Verifies supported DIMM ranks for Gigabyte servers |
| `processor_matcher.py` | Matches processor models to their family and line |
| `rework_family.py` | Re-processes and corrects processor family data |
| `rework_processorfamily.py` | Re-processes and corrects processor family mapping |
| `merging.py` | Merges output data from the Gigabyte scripts |
