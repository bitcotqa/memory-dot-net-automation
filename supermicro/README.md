# Supermicro Memory Automation Scripts

QA automation scripts for verifying Supermicro memory compatibility data on memory.net.

| Script | Purpose |
|---|---|
| `supermicro_category.py` | Verifies product category for Supermicro systems |
| `supermicro_chipset.py` | Verifies chipset details |
| `supermicro_dimm_rank.py` | Verifies supported DIMM ranks |
| `supermicro_normalised.py` | Normalizes and verifies Supermicro product and memory data |
| `supermicro_processor_family.py` | Verifies processor family and product line |
| `supermicro_product_id.py` | Verifies product IDs and model numbers |
| `memory_extractor.py` | Extracts memory specification data from Supermicro product pages |
| `dimm_rank_combined_test.py` | Runs combined DIMM rank verification tests |
