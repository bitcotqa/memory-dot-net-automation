# Cisco Memory Automation Scripts

QA automation scripts for verifying Cisco server memory compatibility data on memory.net.

| Script | Purpose |
|---|---|
| `cisco.amd.py` | Verifies memory data for Cisco AMD-based servers |
| `cisco.intel.py` | Verifies memory data for Cisco Intel-based servers |
| `cisco_normalization.py` | Normalizes and verifies Cisco product and memory data |
| `cisco_processor_family_and_line.py` | Verifies processor family and product line |
| `cisco_server_dimm_ranks.py` | Verifies supported DIMM ranks for Cisco servers |
| `merge.py` | Merges output data from the Cisco scripts |
| `reintel.py` | Re-processes and verifies Intel server data |
