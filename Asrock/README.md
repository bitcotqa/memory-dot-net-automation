# Asrock Memory Automation Scripts

QA automation scripts for verifying Asrock memory compatibility data on memory.net.

| Script | Purpose |
|---|---|
| `asrock_chipset.py` | Verifies chipset details for Asrock motherboards |
| `asrock_dimmrank.py` | Verifies supported DIMM rank (single/dual/quad) |
| `asrock_module_capacity_mb.py` | Verifies supported memory module capacity per motherboard |
| `asrock_processor_family_line.py` | Verifies processor family and product line |
| `AMD_speed_mapping.py` | Maps and verifies memory speeds for AMD platforms |
| `intel_speed_mapping.py` | Maps and verifies memory speeds for Intel platforms |
